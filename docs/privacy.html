同帧

隐私协议

最近更新日期：2026年9月12日 · 生效日期：2026年7月16日

引言

欢迎使用「同帧」（以下简称「本应用」）。本应用由海南一米飞鱼科技有限公司（以下简称「我们」）开发与运营。

本应用面向个人用户，用于创建主题、拍摄照片并对齐记录时间中的变化。我们重视您的个人信息与影像内容，并会按照本《隐私协议》（以下简称「本协议」）说明的范围与方式进行处理。

请您在使用本应用前仔细阅读并理解本协议。您下载、安装、启动或继续使用本应用，即表示您已阅读并同意本协议；若您不同意，请停止使用并卸载本应用。

本协议描述的是本应用当前版本的信息处理规则。我们可能随着功能演进调整处理方式；发生重大变更时，我们将更新本协议，并以应用内提示等合理方式告知您，在法律要求时重新征得您的同意。

一、定义与适用范围

1.1 「个人信息」：指以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息。

1.2 「业务数据」：指您在本应用中创建或生成的主题信息（名称、备注、地点、拍摄周期、提醒、对齐模式、水印配置等）、拍摄的照片文件及相关衍生文件、照片备注、对齐参考标记、应用内偏好设置等。

1.3 本协议适用于您通过 iOS / Android 安装并使用本应用当前正式版本的功能。系统能力（相机、通知、相册、文件系统等）同时受设备厂商与操作系统隐私规则约束。

二、我们如何收集与使用信息

2.1 您主动提供或使用产品时生成的业务数据
为向您提供主题管理、对齐拍摄、浏览播放、水印、待拍与提醒等功能，本应用需要处理下列信息（通常仅在您主动操作时产生）：
（1）主题相关：主题名称、备注、地点、封面关联、拍摄周期、提醒开关与提醒时刻、对齐模式、摄像头方向与构图方向、水印开关及文案/位置/排列等配置；
（2）照片相关：您拍摄后保存在应用内的图片文件、拍摄时间、备注、存储占用、是否作为对齐参考等元数据；
（3）偏好设置：默认对齐模式、默认播放间隔、首页布局与默认排序方式等。

上述信息用于：组织与展示主题；对齐拍摄与预览；播放与水印叠加；待拍判定与提醒调度；记住您的应用设置。

2.2 当前版本的存储与处理方式
在当前版本中，上述业务数据主要用于在您的设备上实现产品功能，并由本应用在设备本地进行存储与读取。我们提供功能时以实现您在本机上的记录、浏览与提醒为目的，不会超出实现功能所必要的范围处理前述信息。

2.3 设备权限相关信息
我们仅在实现相应功能所必需时申请权限，并在您授权后于相关场景使用：
（1）相机权限：用于您进入拍摄页时的取景与拍照，不会在您未使用拍摄功能时静默开启相机采集；
（2）通知权限：在您为主题开启「拍摄提醒」并授权后，用于在计划时刻由系统展示提醒通知；通知内容一般用于提示存在待拍摄主题，不包含您的照片内容本身。

当前版本不申请相册 / 媒体库写入权限。删除主题时仅清除本应用内的本地照片与记录，不会写入系统相册。

您可在系统设置中随时关闭上述权限。关闭后，对应功能可能无法使用；例如关闭通知后，应用内「待拍」标记仍可按规则显示，但系统可能不再展示提醒。

2.4 我们不会以之为目的从事的行为
（1）不强制要求您提供手机号、身份证号等仅用于注册登录的身份信息（当前版本无账号登录要求）；
（2）不基于您的照片内容进行广告定向推送，不出售您的照片；
（3）不申请与当前功能无关的权限（如通讯录、麦克风等）。若系统或组件提示了与功能无关的授权，您有权拒绝。

2.5 运行与质量相关的技术信息
为保障安装、更新与稳定运行，操作系统、应用商店或开发框架可能处理设备型号、系统版本、应用版本号、崩溃诊断信息等。该类处理通常遵循系统或应用商店规则；我们不会借此识别您的影像内容用于与产品无关的目的。

三、本地通知与「待拍」

3.1 「待拍」是应用内根据您设定的拍摄周期计算得出的状态，显示在首页等界面，其展示不依赖通知权限。

3.2 「拍摄提醒」为可选功能。开启并获授权后，本应用会在设备上预约通知，由系统在约定时刻展示。同一次到期提醒按产品规则不重复连催；多个主题同一时刻到期时可能合并提示。

3.3 您删除主题、修改周期或提醒、关闭提醒或关闭系统通知权限后，相关预约将按应用逻辑取消或不再新增。

四、信息的存储、期限与安全

4.1 存储与处理：当前版本中，业务数据保存在您使用的移动设备上的应用存储空间内，用于支持本机功能。

4.2 存储期限：在您通过应用内功能删除相应内容、卸载应用，或操作系统回收相关存储之前，相关数据将保留以供您继续使用。

4.3 安全措施：我们采取合理可行的技术与管理措施保护应用内数据（例如使用应用私有存储空间）。请理解：任何措施都无法保证绝对安全；设备失窃、越狱/Root、恶意软件、他人使用已解锁设备、系统备份被他人读取等，可能超出本应用控制范围。请您妥善保管设备解锁方式。

4.4 卸载与系统备份：卸载本应用可能导致应用内数据被系统删除。若您开启了操作系统或厂商提供的备份/同步，应用数据是否进入厂商备份空间取决于系统设置，请您自行查阅并管理。

五、功能演进与规则更新说明

5.1 本应用可能持续迭代。未来若增加账号、多端同步、云端备份或其他需要将业务数据传输至服务器处理的功能，我们将：
（1）更新本协议，说明收集/使用的目的、方式、范围与保存地点；
（2）在法律要求时，通过弹窗、设置页提示等方式告知您，并取得必要同意；
（3）为您提供合理的控制方式（例如是否开启同步、退出登录、删除云端数据等，以实现版本为准）。

5.2 在相关能力上线并经您按提示确认之前，我们不会以本协议未载明的云端业务目的处理您的照片与主题内容。

六、共享、转让与公开披露

6.1 我们不会出售您的个人信息或照片内容。

6.2 除为实现本协议所述功能所必需、或本协议另有说明、或依法需要外，我们不会向无关第三方共享您的业务数据。若未来因云服务等确需委托处理，我们将要求受托方依法保护您的信息，并仅在实现目的所需范围内处理。

6.3 在以下情形中，我们可能在法律要求的范围内依法处理信息（以适用法律为准）：
（1）与国家安全、国防安全直接相关的；
（2）与公共安全、公共卫生、重大公共利益直接相关的；
（3）与犯罪侦查、起诉、审判和判决执行等直接相关的；
（4）出于维护您或其他个人的生命、财产等重大合法权益但又很难得到本人同意的；
（5）法律、行政法规规定的其他情形。

6.4 若因合并、分立、解散、收购、资产转让等涉及个人信息转移，我们将要求继受方继续受本协议约束，并依法履行告知与征得同意等义务（如适用）。

七、第三方服务与操作系统

7.1 本应用运行于移动操作系统，并可能调用系统提供的能力（相机、通知、文件系统、安全组件等）。系统组件的信息处理规则，请同时参阅 Apple、Google 或设备厂商的说明与您的系统设置。

7.2 若您将照片导出到系统相册，导出后的副本将受系统相册及其他应用访问规则约束。

7.3 匿名使用统计（友盟+ U-App）
在您于首次启动同意，或在「设置 → 隐私协议」页右上角同意后，本应用会接入友盟+移动统计 SDK，用于了解应用启动与功能使用情况、改进产品体验。可能处理的信息包括：设备标识相关信息、系统与应用版本、匿名使用行为（如启动、进入拍摄、保存照片等事件）。

该类统计不包含您的主题名称、照片内容、备注正文等业务数据。您可随时在「隐私协议」页右上角撤回统计；撤回后本应用将不再向友盟初始化/上报新的统计数据。

友盟作为受托处理方，其处理规则亦受其自身隐私政策约束。您未同意或已撤回时，我们不会为此目的启用该 SDK 的采集。

7.4 当前版本不以广告 SDK 为主要能力。若后续引入其他必要的第三方服务，我们将在更新说明与本协议中补充服务商、目的与您的控制方式。

八、您的权利与控制

在适用法律允许的范围内，您可以：

8.1 访问与更正：在应用内查看、编辑主题与照片备注等您录入的内容；

8.2 删除：删除单张照片或主题（以实现版本提供的删除/迁移能力为准）；

8.3 权限管理：在系统设置中管理相机、通知等权限；

8.4 停止使用：停止使用并卸载本应用；

8.5 设置与同意管理：在「设置」中调整默认对齐、默认播放间隔、默认排序方式等偏好；在「隐私协议」页右上角可「同意」或「撤回」匿名使用统计。

若未来提供账号或云端数据管理能力，我们将补充查询、更正、删除云端副本等路径。

九、未成年人保护

本应用并非专门面向儿童设计。若您为未满十四周岁的未成年人，请在监护人陪同下阅读本协议，并在监护人同意后使用。

我们不会主动收集未成年人的个人身份信息用于注册。若监护人发现未成年人在未经同意的情况下提供了依法需监护人同意的信息，请通过本协议载明的方式联系我们，我们将依法及时处理。

十、跨境传输

如无另行说明，我们不会主动将您的业务数据跨境传输至境外用于本协议未载明的目的。若因系统备份、应用商店分发或您使用的第三方工具导致数据离开本机，相关处理可能受系统或该第三方规则约束，请您自行评估。若未来服务架构涉及跨境存储或处理，我们将依法告知并履行必要合规义务。

十一、本协议的更新

我们可能因功能变更、法律法规变化或服务调整修订本协议。更新后的协议将在「设置 → 关于 → 隐私协议」公布，并更新「最近更新日期」。

若更新构成重大变更（例如新增云端处理、扩大收集范围、改变使用目的），我们将以应用内提示或其他合理方式通知您，并在需要时重新征得同意。

更新生效后您继续使用本应用，即视为知悉更新内容；若您不同意，请停止使用并卸载本应用。

十二、适用法律与争议解决

本协议的订立、效力、解释、履行与争议解决，适用中华人民共和国大陆地区法律法规（不含冲突法）。

因本协议引起的或与本协议有关的争议，双方应尽量友好协商；协商不成的，任何一方可向有管辖权的人民法院提起诉讼。

十三、联系我们

如您对本协议或个人信息保护事宜有疑问、投诉或建议，可通过应用商店的应用页反馈入口，或开发者在应用商店留存的联系方式与我们联系。我们将在核实后尽快处理。
